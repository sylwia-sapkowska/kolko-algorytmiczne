# Koło algorytmiki i programowania dla dziewcząt

Materiały z zajęć: algorytmika oraz równoległy bootcamp z C++. Spotykamy się w piątki o 17:00.

Strona zajęć jest dostępna po włączeniu GitHub Pages dla katalogu `docs/` na gałęzi `main`.

## Układ repozytorium

| Katalog | Zawartość |
| --- | --- |
| [`docs/`](docs/) | publiczna strona GitHub Pages i prezentacje |
| [`bootcamp/`](bootcamp/) | kod oraz ćwiczenia z Bootcampu C++ |
| [`algorytmika/`](algorytmika/) | zadania i materiały algorytmiczne |
| [`rozwiazania/`](rozwiazania/) | rozwiązania dla prowadzącej; nie publikuj ich przed zajęciami |

## Publikacja strony

W ustawieniach repozytorium otwórz **Settings → Pages** i wybierz: **Deploy from a branch**, gałąź `main`, katalog `/docs`. Po opublikowaniu adres będzie miał postać `https://<nazwa-uzytkownika>.github.io/<nazwa-repozytorium>/`.

## Dodawanie kolejnych zajęć

1. Utwórz katalog, np. `docs/slajdy/02-zmienne-i-warunki/`.
2. Umieść w nim samodzielny plik `index.html` prezentacji.
3. Dodaj odnośnik na [`docs/slajdy/index.html`](docs/slajdy/index.html) oraz materiały w odpowiednim katalogu.
